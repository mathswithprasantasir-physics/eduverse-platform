# EduVerse - Complete Educational Platform

## Features
- 📚 Support for WBBSE, WBCHSE, ISC, ICSE, CBSE boards
- 📝 Previous Year Questions (PYQs) with solutions
- 📖 Subject notes and study materials
- 📗 Book solutions for popular textbooks
- 🔍 Advanced filtering by year, chapter, difficulty, topic
- 🌓 Dark/Light mode support
- 📐 LaTeX rendering for mathematical content
- 🖼️ Image embedding support
- 💾 JSON-based content management
- 🔄 Version control ready with GitHub
